# HackerSpace

**HackerSpace** — образовательная веб-платформа для самостоятельного изучения программирования с помощью заданий, генерируемых искусственным интеллектом.

Дипломный проект.

Онлайн-демонстрация временно недоступна: сервер проекта больше не поддерживается. Исходный код и материалы проекта доступны в этом репозитории.

## О проекте

Цель проекта — дать начинающим разработчикам возможность практиковаться в программировании: получать задания разного уровня сложности, писать решения во встроенном редакторе и получать обратную связь от AI-модели.

Платформа объединяет пользовательскую часть, серверную логику на PHP, базу данных MySQL и интеграцию с OpenRouter API.

## Основные возможности

- **Регистрация и авторизация.** Создание аккаунта, вход в систему и управление пользовательской сессией.
- **Профиль пользователя.** Просмотр данных профиля, выход из аккаунта и удаление учётной записи.
- **Генерация заданий.** Получение заданий по выбранному языку программирования и уровню сложности.
- **Редактор кода.** Встроенный редактор CodeMirror с подсветкой синтаксиса.
- **AI-оценка решений.** Отправка решения модели и получение обратной связи по корректности, эффективности и читаемости кода, а также рекомендаций по улучшению.
- **Обратная связь.** Форма отправки сообщения администрации проекта с использованием PHPMailer.
- **Раздел для разработчиков.** Отдельная информационная страница с материалами для начинающих.

**Важно:** оценка решения выполняется языковой моделью и носит рекомендательный характер. Проект не следует описывать как полноценную систему запуска пользовательского кода в изолированной среде: в опубликованной реализации проверен именно AI-анализ отправленного решения.

## Технологии и инструменты

### Frontend

- HTML5
- CSS3
- JavaScript
- CodeMirror — редактор кода с подсветкой синтаксиса
- Font Awesome — иконки интерфейса

### Backend

- PHP
- MySQL / MySQLi
- OpenRouter API — генерация заданий и AI-оценка решений
- cURL — HTTP-запросы к API
- PHPMailer — отправка сообщений обратной связи по SMTP

### Среда разработки

- Visual Studio Code

## Требования и настройка для локального запуска

Для восстановления проекта в локальной среде понадобятся:

- веб-сервер с поддержкой PHP;
- PHP с расширениями `mysqli` и `curl`;
- MySQL или совместимая СУБД;
- API-ключ OpenRouter;
- SMTP-учётные данные, если требуется работа формы обратной связи;
- доступ к CDN, с которого загружаются ресурсы CodeMirror и Font Awesome.

### Подготовка

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Oleeggg/HackerSpace.git
   ```

2. Создайте базу данных MySQL и таблицу пользователей. В текущем коде используются таблица `users` и поля `id`, `login`, `email`, `pass`.

3. Настройте параметры подключения к базе данных в PHP-файлах проекта.

4. Укажите собственный OpenRouter API-ключ и необходимые параметры модели в конфигурации проекта.

5. При необходимости настройте SMTP-параметры для PHPMailer.

6. Запустите проект через локальный PHP-веб-сервер или Apache/Nginx с PHP и откройте `index.php` в браузере.

> **Примечание по конфигурации:** репозиторий содержит историческую учебную реализацию. Перед локальным запуском необходимо проверить и заменить демонстрационные параметры подключения к БД, API и SMTP. Не используйте реальные пароли и API-ключи в файлах, которые отправляются в публичный Git-репозиторий. Для дальнейшего развития проекта рекомендуется вынести секреты в переменные окружения или локальный конфигурационный файл, исключённый из Git.
>
> В исходниках также включены настройки cookie с флагом `Secure`. Для локального запуска учитывайте, что такой cookie обычно требует HTTPS; не отключайте защиту на публичном сервере ради локального тестирования.

## Статус проекта

Проект выполнен в рамках дипломной работы. Разработка исходной версии завершена, однако публичный сервер больше не поддерживается, поэтому онлайн-демонстрация сейчас недоступна. Репозиторий сохранён для демонстрации кода, реализованного функционала и использованных технологий.

## Возможные направления дальнейшего развития

- вынести секреты и параметры окружения из исходного кода;
- добавить SQL-скрипт для создания и заполнения базы данных;
- подготовить воспроизводимую конфигурацию локального запуска;
- разделить обработчики, бизнес-логику и представление;
- добавить автоматические тесты;
- рассмотреть запуск пользовательского кода в отдельной изолированной среде, если такая функциональность потребуется в будущем.
